# Haunt - Project Structure

## Folder Organization

**engine/**  
Owner: Ghost Builder  
Contains the accessibility testing engine that drives ghost personas through web applications.

**demo-site/**  
Owner: House Builder  
Contains the example web application used for testing and demonstrations.

**dashboard/**  
Owner: House Builder  
Contains the dashboard for viewing and analyzing accessibility test results.

**runs/**  
Writer: Ghost Builder  
Reader: House Builder  
Contains test run results generated by the engine and consumed by the dashboard.

**runs/samples/**  
Owner: House Builder  
Contains example test runs for development and testing purposes.

**contract/**  
Owners: Ghost Builder & House Builder (shared)  
Defines the data contract between the engine and dashboard - the shared format for test runs and results. Contains:
- `example-run.json` - Sample test run data
- `run-format.md` - Documentation of the JSON format

**diary/**  
Owners: Ghost Builder & House Builder (shared)  
Contains project notes, decisions, and documentation from the hackathon.

## Data Flow

1. Ghost Builder's engine runs tests and writes JSON files to `runs/`
2. House Builder's dashboard reads those JSON files and displays the results
3. The `contract/` folder defines the exact format both sides must follow
